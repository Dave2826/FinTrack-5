# Índice de actividades

Esta carpeta organiza las actividades sin mover archivos existentes. Así se
conservan las rutas que usan el código, las pruebas, el README principal y la
documentación ya entregada.

Cada actividad incluye:

- `evidencias/`: destino para nuevas capturas, respuestas o transcripciones.
- `documentacion/`: referencia a sus documentos existentes.
- `operaciones/`: referencia a sus operaciones GraphQL y variables existentes.

| Carpeta | Actividad | Material original |
| --- | --- | --- |
| `actividad03` | Roles y permisos base | `evidencias/actividad3/` |
| `actividad04` | Configuración de permisos | `evidencias/actividad4/` |
| `actividad05` | Contrato de permisos | `evidencias/actividad5_configuracion_permisos/` |
| `actividad06` | Control de acceso por rol | `evidencias/actividad6_control_acceso/` |
| `actividad07` | Balances | `evidencias/actividad7/` |
| `actividad01p3` | Unidad III, actividad 1: dashboard financiero | `evidencias/unidad3_actividad1_dashboard/` |
| `actividad02p3` | Unidad III, actividad 2: dashboard administrativo | `docs/unidad3_actividad13/` |
| `actividad03p3` | Unidad III, actividad 3: matriz de roles y permisos | `docs/unidad3_actividad14/` y `evidencias/unidad3_actividad14/` |

No se deben mover los archivos fuente a estas carpetas sin actualizar primero
las referencias del proyecto.
